# 지원모아

- 사이트: https://jiwonmoa.orfa.shop
- 갱신: 매일 오전 6시 30분(한국 시간) 공공 API에서 새로 수집한다. 수집에 10분쯤 걸린다.

정부·지자체·공공기관의 지원사업(모집 공고와 상시 제도)을 한곳에 모아, 지역과 대상(청년·시니어·농업인·소상공인 등)으로 찾아보는 웹 서비스.

## 구성

```
collector/        공공 API 수집 → SQLite 정리 → 화면용 자료 생성 (Python 표준 라이브러리만 사용)
site/             정적 웹 화면 (HTML·CSS·JS, 빌드 도구 없음)
  vendor/         대한민국 지도 SVG
deploy/           서버 운영: 호스팅 준비(setup_hosting.sh), 매일 갱신(update.sh), 안내(README.md)
docs/api-specs/   API 규격(Swagger) 원본
```

## 준비

1. Python 3.9 이상
2. [공공데이터포털](https://www.data.go.kr)에서 아래 '자료 출처'의 API 4개를 활용 신청하고 일반 인증키를 받는다.
3. `.env.example`을 `.env`로 복사하고 `DATA_GO_KR_KEY`에 인증키를 넣는다. `.env`는 저장소에 올리지 않는다.

## 실행

```
python collector/probe.py                 # API 연결 점검(출처별 3건)
python collector/collect.py               # 전체 수집 → data/hub.db (약 5~10분, 국고보조금이 대부분)
python collector/collect.py --reprocess   # 판정 규칙만 고쳤을 때: 새로 받지 않고 다시 정리
python collector/build_site.py            # 화면용 자료 site/data/ 생성
python collector/report.py                # (선택) 점검 보고서 reports/ + 엑셀용 CSV data/export/
```

`site/index.html`을 브라우저로 열면 된다(서버 불필요). 주소 공유·뒤로 가기까지 확인하려면:

```
python -m http.server 8765 --directory site   # http://127.0.0.1:8765
```

수집 자료(`data/`)와 화면용 자료(`site/data/`)는 저장소에 넣지 않는다. 위 순서로 다시 만든다.

규칙을 고친 뒤에는 테스트를 돌린다(표준 라이브러리만, GitHub Actions에서도 같은 명령):

```
python -m unittest discover -s tests -v
```

## 화면

- 탭: 홈 / 모집 공고 / 상시 제도(보조금24)
- 조건: 누구를 위한 지원(18가지), 지역(전국 대상 포함 여부), 신청 상태, 출처. 상시 제도는 분야·지원 방식도 고를 수 있다.
  농업인을 고르면 농업 세부 분야 칩이 나온다. 조건은 주소(#)에 담겨 링크로 공유된다.
- 홈
  - 숫자 타일, 나에게 맞는 지원 찾기(대상 칩)
  - 그래프 6개: 대상별 공고·제도 수(나비 그래프 — 왼쪽 공고, 오른쪽 제도, 막대 길이는 제곱근 눈금), 지역 지도(공고 | 제도), 마감 달력(이번 달부터 석 달, 보통 달력 모양, 날짜별 마감 수 — 누르면 그날 마감 목록),
    공고는 언제 올라오나요(국고보조금, 작년·올해, 달별 | 누적), 상시 제도 분야 | 지원 방식, 곧 올라올 수 있는 공고(작년 이맘때 접수를 시작한 국고보조금 공고)
  - 목록 3개: 마감이 가까운 공고, 새로 올라온 공고(최근 7일), 많이 찾는 지원사업(누적 조회수)
  - 홈에서 고른 지역이 모든 숫자와 그래프에 적용된다.
- 용어: 화면 글은 세 낱말만 쓴다. **지원사업** = 둘을 합친 말, **모집 공고**(줄여 '공고') = 신청 기간이 있는 공고(기업마당·K-Startup·국고보조금),
  **상시 제도**(줄여 '제도') = 기간 없이 늘 신청하는 제도(보조금24). '공모'·'상시 지원제도'·'지금 모집 중'은 쓰지 않는다
  (공고 제목 원문과 공공데이터 이름 「국고보조금 공모」 같은 고유 이름은 그대로).
- 색 체계(`site/style.css` 맨 위 변수): 색은 뜻에 붙는다 — 같은 뜻 = 같은 색, 한 색 = 한 뜻.
  회색 = 뼈대(글자·면·선), 검정 = 고른 것, 노랑 = 화면마다 하나뿐인 주요 행동, 파랑 = 모집 공고, 초록 = 상시 제도
  (탭 앞 점·숫자 타일·그래프·지도·도넛), 빨강 = 오늘~D-3 마감·오류, 주황 = 7일 안 마감. 그래프 비교 대상(작년 등)은 회색.
  색마다 단계 변수(`--blue-100`~`--blue-900` 등)가 있고 그래프·지도·달력은 이 변수를 쓴다.
- 그래프 움직임: 화면에 들어올 때(스크롤로 화면 밖에 나갔다 돌아올 때, 다른 탭에서 홈으로 돌아올 때도) 막대가 자라나고 선이 그려진다. 지역·전환 단추로 바뀐 그래프만 다시 움직인다.
  가리키면 나머지 막대가 옅어진다. 운영체제의 '움직임 줄이기' 설정이면 움직이지 않는다(`app.js`의 `setupMotion`).
- 날짜 없는 공고('예산 소진 시까지', '상시')에는 마감일을 만들지 않는다.
- 상세: 출처가 따로 주는 조건(나이·소득·성별·개인·가구 특성·업종·창업 기간·사업 예산·사업비 분담 등)과
  글(선정 기준·구비 서류·신청 제외 대상·근거 법령 등)을 붙인다. '공고문 참조'·'해당없음' 같은 빈말은 넣지 않는다.
  국고보조금 공모의 사업 예산은 사업 전체 규모이지 한 곳이 받는 돈이 아니다. 자부담이 0이어도 '없음'으로 읽힐
  표시는 하지 않는다(글에만 자부담이 적힌 공고가 있다).
- 기업마당 공고는 공고문·첨부 파일 링크를 붙인다(파일은 기업마당 서버에서 바로 받는다). 상세 화면에서만 쓰는 것
  (제도 상세 글, 공고 첨부 파일)은 목록 파일과 떼어 `site/data/sd/`에 두고 열 때만 읽는다.

## 규칙이 있는 곳

| 내용 | 위치 |
|---|---|
| 지역·농업·대상(personas)·지원 방식 판정, 상세 조건·글 | `collector/normalize.py` |
| 신청기간 종류(기간·상시·소진 시·매월·분기·매년·사유 발생 후·기관별·신청 불필요·확인 필요) | `collector/normalize.py`의 `PERIOD_RULES`·`STATUS_BY_TYPE`, 화면은 `site/app.js`의 `STATUS_BY_TYPE` |
| 같은 공고 재게시 정리(출처·제목·기관·기간·지역이 모두 같을 때만) | `collector/build_site.py`의 `dedupe_notices` |
| 농업 세부 분야 칩 | `collector/build_site.py`의 `AGRI_TOPICS` |
| 홈 집계(지역·대상별 건수, 공모 달, 많이 찾는 제도) | `collector/build_site.py`의 `service_counts`, `open_months`, `top_services` |
| 곧 열릴 수 있는 공모(같은 사업 묶기) | `collector/build_site.py`의 `upcoming_calls`, `program_key` |
| 화면 동작·그래프 | `site/app.js` |
